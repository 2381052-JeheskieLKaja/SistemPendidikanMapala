# Frontend — Sistem Pendidikan MAPALA Eden Club UNAI

React + Vite + Tailwind CSS. Petunjuk instalasi, konfigurasi, dan cara menjalankan ada di [README utama](../README.md).

```bash
cp .env.example .env
npm install
npm run dev     # http://localhost:5180 (proxy /api ke backend :4100)
npm run build   # build produksi ke dist/
```
